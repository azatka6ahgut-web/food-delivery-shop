зн# 🥦 ЗелёнаяКорзина — онлайн магазин доставки продуктов

Пет-проект: онлайн магазин доставки продуктов питания. Backend на FastAPI + PostgreSQL,
простой frontend на HTML/CSS/JS. Сделан как учебная база для практики Python-автотестирования
(pytest + Playwright) — реалистичное CRUD-приложение с авторизацией, корзиной, заказами и
мок-оплатой.

## Функциональность

- Регистрация и вход (JWT)
- Каталог продуктов с фильтрацией по категориям
- Корзина: добавление, изменение количества, удаление товаров
- Оформление заказа с адресом доставки
- Мок-оплата картой (эмулирует реальный платёжный шлюз для тестирования):
  - любая карта → успешная оплата
  - карта, оканчивающаяся на **0002** → отклонена (для негативных тест-кейсов)
- История заказов пользователя
- Роли: обычный пользователь видит только свои заказы, админ — все

## Стек

- **Backend:** FastAPI, SQLAlchemy, PostgreSQL, JWT (python-jose), passlib (bcrypt)
- **Frontend:** чистые HTML/CSS/JS (без фреймворков)
- **Инфраструктура:** Docker, Docker Compose
- **Тесты (будем добавлять по ходу обучения):** pytest, Playwright, Allure

## Запуск проекта

Требуется установленный Docker и Docker Compose.

```bash
docker compose up --build
```

После запуска:
- Сайт: http://localhost:8000
- Swagger-документация API: http://localhost:8000/docs
- Health-check: http://localhost:8000/health

При первом запуске каталог автоматически заполняется тестовыми продуктами.

## Основные API-эндпоинты (полный список и возможность потыкать руками — в /docs)

| Метод | Путь                        | Описание                              |
|-------|-----------------------------|----------------------------------------|
| POST  | /auth/register               | Регистрация                           |
| POST  | /auth/login                  | Вход, получение JWT                   |
| GET   | /products                    | Список продуктов (+ фильтр category)  |
| POST  | /cart/items                  | Добавить товар в корзину              |
| PUT   | /cart/items/{id}              | Изменить количество                   |
| DELETE| /cart/items/{id}              | Удалить товар из корзины              |
| POST  | /orders                      | Оформить заказ из корзины             |
| GET   | /orders                      | Список своих заказов (админ — все)    |
| POST  | /payment/{order_id}          | Оплатить заказ (мок-оплата)           |
